# Paletter

Färgpaletter för Noctalia. Varje `.json` här länkas till
`~/.config/noctalia/palettes/` och kan väljas i Noctalias inställningar
(Theme → källa "Custom").

Kopierade från [bwoah-md/dotfiles](https://github.com/bwoah-md/dotfiles/tree/main/noctalia/palettes).
Många av dem kommer i sin tur från
[ezequielgk/noctalia-colorschemes](https://github.com/ezequielgk/noctalia-colorschemes).

Format: <https://docs.noctalia.dev/noctalia/theming/palette/#palette-json>
